# Tonic — YouTube-музыка без подписки

Android-приложение (Kotlin + Jetpack Compose + Media3). Поиск и аудио берутся через NewPipeExtractor, без YouTube Premium.

**Возможности:** поиск, фоновое воспроизведение с уведомлением, мини-плеер и полноэкранный плеер, **скорость 0.5–2.0×**, **тональность −6…+6 полутонов**, избранное и плейлисты, синхронизация с Google Drive.

## 1. Сборка APK через GitHub
1. Создайте **приватный** репозиторий на github.com (в репозитории лежит ключ подписи).
2. Загрузите в него всё содержимое этой папки (Add file → Upload files). Важно, чтобы попали папка `.github/workflows/build.yml` и файл `app/tonic.keystore`.
3. Откройте вкладку **Actions** → **Build APK** → **Run workflow** (при загрузке в ветку main сборка стартует сама).
4. Через 5–8 минут откройте завершённый запуск → внизу **Artifacts → Tonic-apk** → скачайте, распакуйте `app-debug.apk`.
5. Установите на телефон (разрешите установку из неизвестных источников).

Если сборка упала: откройте запуск → шаг **Build debug APK** → скопируйте красные строки ошибки и пришлите мне.

## 2. Вход через Google (синхронизация и импорт плейлистов)
Без этого шага музыка работает. Вход нужен только для Google Drive и импорта плейлистов из аккаунта.
Плейлисты можно импортировать и без входа: Настройки → Синхронизировать → «Импорт по ссылке».

1. console.cloud.google.com → создайте проект.
2. **APIs & Services → Library**: включите **Google Drive API** и **YouTube Data API v3**.
3. **OAuth consent screen / Google Auth Platform**: тип External, название и почта.
   - **Data access (Scopes)**: добавьте `.../auth/drive.appdata` и `.../auth/youtube.readonly`.
   - **Audience → Test users**: добавьте свой Gmail. Без этого Google блокирует вход, и приложение показывает «16: Cancelled».
4. **Credentials → Create credentials → OAuth client ID** → тип **Android**:
   - Package name: `com.tonic.player`
   - SHA-1: `5D:2F:F6:26:5D:4A:69:F2:5A:0C:50:37:DA:14:52:DA:AD:88:72:6A`
5. В приложении: шестерёнка → **Синхронизировать** → «Войти через Google» или «Импорт из аккаунта».
6. На экране «Приложение не проверено» нажмите «Дополнительно» → «Перейти», затем разрешите доступ.

## 3. Если YouTube перестал отдавать треки
YouTube регулярно меняет защиту. Откройте github.com/TeamNewPipe/NewPipeExtractor/releases, возьмите номер последней версии и замените его в `app/build.gradle.kts` в строке `NewPipeExtractor:v0.26.5`. Закоммитьте — APK соберётся заново.

## 4. Что можно поменять
- Название: `app/src/main/res/values/strings.xml`.
- Пакет: `applicationId` и `namespace` в `app/build.gradle.kts` (тогда SHA-1 регистрируйте для нового пакета).
- Цвета: `TonicTheme` в `UI.kt`.

## Ограничения
- Синхронизация объединяет списки (удаление трека на одном устройстве не удаляет его на другом).
- Приложение нарушает условия сервиса YouTube, в Google Play не опубликуется — только для личного использования.
- Ключ подписи лежит в репозитории: держите репозиторий приватным.

## Лицензия
Проект распространяется по **GNU GPL v3** (файл `LICENSE`, та же лицензия, что у ArchiveTune и ViMusic). Оформление вдохновлено ViMusic и ArchiveTune; их код в проект не копировался. Если будете раздавать APK другим людям, по GPL нужно выложить и исходный код.

## Эффект «жидкого стекла»
Нижняя панель, мини-плеер, карточки и кнопка Play — полупрозрачные панели со светлым бликом по краю на фоне цветных пятен и размытой обложки играющего трека (размытие обложки работает на Android 12+, на старых версиях фон без обложки).

## Интерфейс (в стиле ViMusic)
Боковая панель с вертикальными вкладками: Главное, Исследуйте (поиск), Музыка, Плейлисты, Исполнители. Шестерёнка открывает настройки: Внешний вид, Плеер, Кэш, База данных, Синхронизировать, Прочее, О приложении. «Жидкое стекло» включается в Настройки → Внешний вид → Стиль.

Не реализовано: «Оффлайн» (скачивание треков), «Альбомы», «Локальное», выбор шрифта.

## Скорость и тональность
В полноэкранном плеере нажмите три точки справа вверху: «В избранное», «Добавить в плейлист», «Скорость и тональность».
